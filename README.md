# Учет товаров на складе

### 1. Товар
- `ID` 
- `Название` 
- `Категория` 
- `Количество` 
- `Цена` 
- `Минимальный остаток`

### 2. Основные функции
#### Добавить товар
Название -> Категория -> Цена -> Количество

#### Приход товара
Выбрали товар -> указали количество -> остаток увеличился

#### Расход товара
Выбрали товар -> указали количество -> остаток уменьшился

#### Список товар
Показать все товары и их текущие остатки

#### Поиск
Найти товар по названию
